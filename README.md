# コエペース（仮称）

マラソンのペース配分を音声で教えてくれるアプリ。GPSを使わず、時間だけで「◯km予定地点です」と読み上げます。

- 仕様と決定の記録は、Claudeのプロジェクト「副業」の仕様メモ・決定記録にあります
- アプリは Expo（React Native）で作ります

## v0.3（2026-11-20）
- 無音の音を流し続けるやり方をやめ、Androidの常駐サービス（`modules/koepace-runner`）で時計と読み上げを持つようにした
- 「計測中」の通知を出して裏で動き続け、読み上げる数秒だけ音楽アプリの音量を下げてもらう（音楽は止めない）
- 最初の記録に変な時刻が入る不具合を修正（記録はサービス側でとる）
